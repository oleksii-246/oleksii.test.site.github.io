Історія авіації

Від перших польотів братів Райт у 1903 році до надзвукових лайнерів — авіація пройшла дивовижний шлях розвитку. З кожним десятиліттям літаки ставали швидшими, безпечнішими та комфортнішими для пасажирів.

Типи літаків

🛫 Пасажирські

Призначені для перевезення людей на великі відстані. Сучасні пасажирські лайнери можуть літати 12+ годин без зупинки.

🚁 Військові

Використовуються для оборони, розвідки та спеціальних місій. Розвиваються з використанням найновіших технологій.

📦 Вантажні

Перевозять товари та обладнання по всьому світу. Деякі літаки можуть перевезти понад 100 тонн вантажу.
